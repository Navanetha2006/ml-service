What is DNA?

The double helix

Two long strands twisted around each other, about 2 nanometres wide. It looks like a twisted ladder, like the one behind this page.

Four letters

The code uses A, T, C and G. A always pairs with T, and C always pairs with G, so each strand predicts the other.

Huge, but tiny

A human genome has roughly 3 billion base pairs and about 20,000 protein-coding genes. Stretched out, the DNA in one cell is around 2 metres long.

When it goes wrong

Cancer starts when mutations pile up in genes that control growth, so cells keep dividing when they should stop.

Build the other strand

Type a DNA sequence (A, T, C, G) and see its matching strand.

Does this project read DNA?

No. The model never sees genes. It uses measurements taken from images of cell nuclei, such as size and edge roughness. Shape is a clue, not a diagnosis.
